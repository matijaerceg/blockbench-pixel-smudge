First public release of Pixel Smudge for Blockbench 5.2+.

Download pixel_smudge.js and install through File > Plugins > Load Plugin from File.

- Continuous color pickup while dragging.
- Adjustable Strength, Pickup, brush size and shape.
- Active-layer painting with native Undo/Redo.
- Duplicate toolbar cleanup and explicit control defaults.

Mirror painting must be off. Samples the active layer only. Screen-space projection and Shift line strokes are disabled.
